# Workshop Materials

Esta carpeta contiene el material adicional generado durante la preparacion:

- `reports/`: informes de verificacion, readiness de GitHub Actions y marco conceptual.
- `artifacts/`: resultados JSON, logs de Yosys/Verilator y paquete comprimido.
- `source-context/`: documentos del repo KA-Memristive-FF usados como contexto.

Para el flujo Tiny Tapeout, lo importante esta en la raiz del repo. Esta carpeta es apoyo para explicar y defender la propuesta durante el workshop.
